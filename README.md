# Deep Current MVP

Telegram Mini App для просмотра публичной статистики, позиций и сделок кошельков Hyperliquid.

## Что уже работает

- рейтинг до 1000 отобранных публичных кошельков и сортировка по качеству/PnL/капиталу/объёму;
- возобновляемая 60D-проверка кошельков: активность за период, минимум 6 закрывающих транзакций, win rate от 60%, положительный 30D PnL и полный доступный диапазон истории;
- реальные mid prices, позиции, Open PnL, история аккаунта и последние закрытия;
- верхняя live-лента крупных действий и цены по WebSocket;
- точная WebSocket-лента 10 активных кошельков плюс фильтрация глобальных сделок по расширенной базе;
- избранное и настройки Telegram-уведомлений в SQLite с автоматическим переносом из localStorage;
- защищённая Telegram initData админ-панель: пользователи, роли, размер базы и статус потоков;
- постоянный серверный collector: Open/Add/Reduce/Close, дедупликация, объединение частичных исполнений и Telegram-уведомления с точным временем;
- новый raw-журнал fills с replay, проверкой непрерывности, scoped-снимками и durable outbox; ордера и funding для просматриваемых адресов догружаются отдельно;
- Copyability Score, честные метки источника/точности и отдельные страницы монет со свечами и smart-money потоком;
- фильтры уведомлений по сумме, монетам, типу события, тихим часам и совпадениям кошельков.
- устанавливаемое PWA: защищённая cookie-сессия браузера, центр уведомлений и Web Push даже при закрытой вкладке.

## Локальный запуск

Текущая контрольная точка и ограничения этапов 2–6: [отчёт](docs/stages-2-6-results.md). Безопасный порядок включения нового collector: [runbook](docs/journal-rollout.md). По умолчанию используется `DC_JOURNAL_MODE=shadow`: сбор есть, внешние уведомления не отправляются.

Подтверждённое ограничение бюджета и новая приоритетная догрузка fills: [только бесплатные источники](docs/free-data-mode.md). Быстрый market BUY/SELL публикуется отдельно от подтверждённого Open/Close; очередь подтверждений видна в `check:journal`.

Для ограниченного пилота Dwellir Hyperliquid Index задай `DC_ARCHIVE_INFO_URL` полным HTTPS `/info` endpoint и перечисли 20–50 публичных адресов в `DC_ARCHIVE_WALLETS`. Только `userFills` этих адресов пойдут через Dwellir; состояния аккаунтов останутся на официальном API, остальные кошельки и ошибки Dwellir автоматически используют официальный источник. Не добавляй URL с ключом в Git.

```bash
npm install
npm run dev
```

Для Telegram-бота скопируй `.env.example` в `.env.local`, задай новый токен, Telegram ID первоначальных администраторов через запятую и публичный HTTPS URL. Сам collector собирает рыночные события и позиции даже без Telegram-токена; без токена отключены только бот, уведомления и Telegram-авторизация админов. Node не загружает `.env.local` сам, поэтому запусти так:

```bash
set -a && source .env.local && set +a && npm run collector
```

Для системных уведомлений один раз создай VAPID-ключи и добавь их в `.env.local`:

```bash
npx web-push generate-vapid-keys
```

Web Push требует HTTPS. На iPhone и iPad он работает после добавления Deep Current на главный экран; разрешение браузер показывает только после нажатия пользователя. Финансовые данные service worker намеренно не кэширует.

Проверки:

```bash
npm test
npm run lint
npm run build
npm run check:live
npm run check:journal
```

`check:realtime` проверяет HTTP/SSE fan-out, а не 1000 полноценных браузеров: `npm run check:realtime -- http://localhost:3001/api/live 1000 60000`.
Copyability показывает модель, не исполненный backtest. Быстрый BUY/SELL публичного рынка не является доказанным Open/Close. История API ограничена; неизвестные даты нельзя восстановить ожиданием или дополнительным браузером.

Проверка кандидатов сохраняется в общей SQLite-базе и безопасно продолжается после остановки. Полный проход по кошелькам с положительным 30D PnL ограничен публичным API и поэтому выполняется отдельным фоновым процессом. `target` задаёт число кандидатов для индивидуальной 60D-проверки, а не число автоматически добавляемых кошельков:

```bash
npm run discover:wallets -- --target=5000
```

На production этот проход нужно запускать ежедневно: приложение принимает только проверки моложе 24 часов и перед показом повторно требует положительный актуальный 30D PnL. Файл SQLite должен лежать на постоянном диске через `DEEPCURRENT_DB_PATH`.

Чистая установка стартует с последнего проверенного реестра из репозитория, поэтому рейтинг не зависит от наличия локальной SQLite при первом запуске. Свежие серверные проверки всегда заменяют snapshot, включая отклонённые кошельки. После полного прохода snapshot обновляется командой `npm run export:wallets` перед сборкой.

Для запуска Mini App нужен публичный HTTPS-домен (например, Vercel) и его URL в BotFather: `/mybots` → бот → **Bot Settings** → **Menu Button**.

Важно: это аналитика публичных данных, не инвестиционная рекомендация. Кандидаты берутся из публичного leaderboard-фида Hyperliquid и добавляются только после индивидуальной проверки критериев выше. SQLite рассчитан на один серверный экземпляр web + collector; перед горизонтальным масштабированием его нужно заменить общей БД.
