# DC Pulse MVP

Telegram Mini App для просмотра публичной статистики, позиций и сделок кошельков Hyperliquid.

## Что уже работает

- рейтинг 200 отобранных публичных кошельков (настраивается до 500) и сортировка по качеству/PnL/капиталу/объёму;
- реальные mid prices, позиции, Open PnL, история аккаунта и последние закрытия;
- верхняя live-лента крупных действий и цены по WebSocket;
- точная WebSocket-лента 10 активных кошельков плюс фильтрация глобальных сделок по расширенной базе;
- избранное в localStorage;
- защищённая Telegram initData админ-панель: пользователи, роли, размер базы и статус потоков;
- Telegram-бот с `/top`, `/watch`, `/stop` и кнопкой запуска Mini App.

## Локальный запуск

```bash
npm install
npm run dev
```

Для бота скопируй `.env.example` в `.env.local`, задай новый токен, Telegram ID первоначальных администраторов через запятую и публичный HTTPS URL. Node не загружает `.env.local` сам, поэтому запусти так:

```bash
set -a && source .env.local && set +a && npm run bot
```

Проверки:

```bash
npm test
npm run lint
npm run build
npm run check:live
```

Для запуска Mini App нужен публичный HTTPS-домен (например, Vercel) и его URL в BotFather: `/mybots` → бот → **Bot Settings** → **Menu Button**.

Важно: это аналитика публичных данных, не инвестиционная рекомендация. Рейтинг сейчас берётся из публичного leaderboard-фида Hyperliquid и фильтруется по капиталу и устойчивой прибыли. Локальная админ-база рассчитана на один прототипный процесс; перед облачным запуском её нужно перенести в постоянную БД, а рейтинг — в собственный проверяемый реестр.
